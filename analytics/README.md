# Module 2 - Analytics and Machine Learning

This module uses the Titanic dataset for data analysis, visualization, classification, imbalance handling, hyperparameter tuning, and regression.

## Tasks Completed

- Data profiling and missing-value analysis
- Missing-value handling using the required threshold rule
- Age and fare analysis with histograms and box plots
- IQR-based outlier detection
- Survival analysis by sex and passenger class
- Correlation heatmap
- Multivariate data visualization
- Standardization check
- Stratified train/test split
- Preprocessing with imputation, encoding, and scaling
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation
- Class imbalance comparison
- SMOTE
- Random Forest GridSearchCV
- OOB score
- Multivariate linear regression
- Model comparison
- Complete pipeline saved using joblib
- Reload and raw-input prediction test
