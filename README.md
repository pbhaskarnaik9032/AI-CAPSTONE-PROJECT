# AI-CAPSTONE-PROJECT

This repository contains the complete capstone project divided into three modules.

## Module 1 - Data Pipeline

- Web scraping using Requests and BeautifulSoup
- Data cleaning and preprocessing
- CSV data storage
- SQLite database
- Primary key and foreign key
- SQL queries and JOIN
- Pandas merge

Folder:

`module1/`

## Module 2 - Analytics and Machine Learning

- Titanic dataset profiling
- Data cleaning
- Exploratory Data Analysis
- Visualization
- Correlation analysis
- Classification
- Logistic Regression
- Decision Tree
- Random Forest
- SMOTE and class balancing
- Hyperparameter tuning
- Linear regression
- Model evaluation
- Complete pipeline saved using Joblib

Folder:

`analytics/`

## Module 3 - Generative AI Support Assistant

- Zepto policy knowledge base with 8 documents
- Text chunking with overlapping chunks
- Sentence Transformer embeddings
- Persistent ChromaDB vector store
- Cosine-similarity retrieval
- Top-3 relevant chunk retrieval
- LangGraph intent classification and routing
- Pydantic structured responses
- FastAPI `POST /ask` API
- Mock LLM mode for reproducible grading
- Optional real LLM integration with structured-output validation and retries
- Docker support

Folder:

`support_assistant/`
